# แม่แบบสัญญาเช่าอาคาร (Thai Building Lease Contract Template)

สร้างสัญญาเช่าอาคารภาษาไทยเป็นไฟล์ Word (.docx) จากไฟล์ข้อมูล JSON
มีข้อสัญญา 23 ข้อ เอกสารแนบท้ายสัญญา และตารางสรุปการชำระเงิน (คำนวณตัวเลขและคำอ่านเงินบาทให้อัตโนมัติ)

## ไฟล์ในโปรเจกต์

| ไฟล์ | คำอธิบาย |
|---|---|
| `generate.js` | สคริปต์สร้างสัญญา |
| `data.example.json` | ตัวอย่างข้อมูล (ข้อมูลสมมติ) |
| `data.blank.json` | ข้อมูลว่าง ใช้สร้างแบบฟอร์มเปล่าสำหรับกรอกด้วยมือ |
| `template/สัญญาเช่าอาคาร_แบบฟอร์มเปล่า.docx` | แบบฟอร์มเปล่าพร้อมพิมพ์ |

## วิธีใช้

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป

```bash
npm install
cp data.example.json data.json      # แล้วแก้ไขข้อมูลใน data.json
node generate.js data.json          # ไฟล์จะอยู่ในโฟลเดอร์ output/
```

สร้างแบบฟอร์มเปล่าใหม่: `npm run blank`

## ช่องข้อมูลหลัก

- `landlord` / `tenant` — ชื่อ ที่อยู่ เลขบัตรประชาชน
- `property` — ที่อยู่อาคาร เลขรหัสประจำบ้าน ลักษณะอาคาร วัตถุประสงค์การเช่า
- `term` — ระยะเวลาเช่า วันเริ่ม/สิ้นสุด ระยะแจ้งต่อสัญญาล่วงหน้า
- `rent` — ค่าเช่าต่อเดือน วันครบกำหนดชำระ จำนวนเดือนที่จ่ายล่วงหน้า
- `deposit` — จำนวนเดือน/ยอดเงินประกัน และหลักฐานการโอน
- `bank` — บัญชีรับค่าเช่าของผู้ให้เช่า
- `late_interest_pct`, `overstay_penalty_per_day` — ดอกเบี้ยค้างชำระ และค่าปรับรายวันกรณีไม่ย้ายออก

ช่องที่ปล่อยว่าง (`""`) จะแสดงเป็นเส้นจุด `.......` ให้กรอกด้วยมือ

## ⚠️ ความเป็นส่วนตัว

**ห้าม commit ข้อมูลจริง** (เลขบัตรประชาชน เลขบัญชี สำเนาเอกสาร) ขึ้น GitHub
ไฟล์ `data.json`, โฟลเดอร์ `output/`, และไฟล์ PDF/รูปภาพ ถูกใส่ไว้ใน `.gitignore` แล้ว
